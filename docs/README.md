## 当前冻结口径

- 包目录：`src/edgetts_arena/`
- 模型状态：`GET /api/v1/system/models`
- Benchmark：同步 `POST /api/v1/benchmark/run`
- 归档标识：`run_id`
- 模型能力：capability-driven
- TTFB：仅真流式模型有效
- 默认模式：Sequential
- MVP：Dummy + Piper + Kokoro；Qwen3-TTS 为 experimental
