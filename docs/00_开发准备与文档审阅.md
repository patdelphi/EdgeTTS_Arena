## 2. 已冻结的关键实现决策

| 决策项 | 统一口径 |
|---|---|
| Python 包目录 | `src/edgetts_arena/` |
| 模型列表 API | `GET /api/v1/system/models` |
| Benchmark API | MVP 使用同步 `POST /api/v1/benchmark/run` |
| Benchmark 标识 | 使用 `run_id`，不使用具有异步含义的 `task_id` |
| 模型能力 | 每个 Adapter 必须声明 `capabilities` |
| 性能统计 | 独立 `MetricsCollector`，Adapter 不维护统一 stats |
| 模型生命周期 | lazy load + 可选 keep-in-memory + 显式 unload |
| 默认调度 | `sequential`；Concurrent 是受 ResourceGuard 约束的压力/吞吐模式 |
| 依赖隔离 | MVP 单兼容环境；冲突模型后续独立 subprocess/venv worker |
| CPU affinity | best-effort；线程数限制是跨平台基础能力 |
| TTFB | 真流式统计首个可播放 chunk；非流式返回 `null` |
| UI | Gradio 6.x 为可选 `[ui]` extra，挂载 `/arena/`，纯 API 不依赖 Gradio |
| UI 参数 | capability-driven；多模型 voice 使用各模型默认值 |
| Blind AB | 揭晓前匿名；全部 sample 评分后 reveal；结果写入 `blind_scores.json` |
| 性能目标 | RTF/RAM/TTFB 是 benchmark target，不是硬编码事实 |

## 5. 实现原则

1. **Capability 驱动**：API/UI 不假设模型能力。
2. **Benchmark 可复现**：报告保存环境、线程、runtime、模型 metadata。
3. **观测与推理解耦**：Adapter 负责生成，MetricsCollector 负责统计。
4. **性能以实测为准**：不把预计数字硬编码为事实。
5. **失败隔离**：单模型异常不导致整轮或主进程退出。
6. **可选依赖隔离**：UI/真实模型 runtime 使用 extras 与独立 CI gate。
7. **Blind 可追溯**：匿名映射和评分与同一 `run_id` 绑定。
