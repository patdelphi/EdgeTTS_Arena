# EdgeTTS-Arena 开发基线与决策记录

> 文档版本：v0.3  
> 基线日期：2026-09-03  
> 状态：**Stage 0~5 implemented / Stage 6 hardening**

## 当前结论

主应用已形成完整 MVP：Adapter/Registry、Piper/Kokoro CPU runtime、FastAPI、Arena UI、Blind AB、标准 repeated Benchmark Suite 和可复现 artifact pipeline 均已实现。

Qwen3-TTS 继续保持 `experimental + unavailable`，直到 CPU runtime、模型包、许可证、内存和 benchmark 全部可复现后再转正式。

## 冻结决策

| 项 | 口径 |
|---|---|
| 包目录 | `src/edgetts_arena/` |
| 单轮 benchmark | 同步 `POST /api/v1/benchmark/run` |
| 标准 suite | 同步 `POST /api/v1/benchmark/suite`，固定 Sequential |
| preset | `config/benchmark_presets.json` TC-01~05 |
| repeats | 默认 warm-up 1 + measured 3 |
| 聚合 | mean/median/min/max/P95/variance，并保留 raw measurements |
| 归档 | `run_id` |
| 性能观测 | MetricsCollector 独立于 Adapter |
| TTFB | 真流式首块；非流式 null |
| UI | Gradio 6.x optional `[ui]`，挂载 `/arena/` |
| Blind | Reveal 后 mapping/ratings 写 `blind_scores.json` |
| 性能目标 | 仅 benchmark target，不硬编码为事实 |
