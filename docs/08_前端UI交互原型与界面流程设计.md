# 前端 UI 交互原型与界面流程设计

> 版本：v0.4 ｜ Stage 4~5 已实现 ｜ Gradio 6.x optional UI

## 1. 运行

```bash
python -m pip install -e ".[ui]"
edgetts-arena serve --ui
```

`http://127.0.0.1:8000/arena/`。

UI 与 FastAPI 同进程，共享 Registry、BenchmarkService、RepeatedBenchmarkService 与 RunArtifactStore；不做本机 HTTP 自调用。

## 2. Arena

- Preset：Custom 或 TC-01~05，选择后自动填充标准文本。
- Models：1~4，2~4 推荐横向对比。
- Sequential 默认；Concurrent 可选。
- threads / speed / seed / voice capability-driven。
- 最多 4 份音频与 metric cards。
- Comparison table。
- ZIP export。

非流式 `ttfb=null` 显示 `N/A (non-streaming)`。

## 3. Standard Benchmark Suite

Stage 5 增加独立区块：

- Cases：TC-01~05 多选。
- Models：1~4 多选。
- Warm-up runs。
- Measured runs。
- CPU threads/model。
- Run standard suite。
- 聚合表：case/model/status/success count/inference mean/RTF mean/RTF P95/RSS mean/CPU mean。
- Suite ZIP export。

Suite 固定 Sequential，不与压力模式混用。

## 4. Blind AB

保持 Stage 4 规则：至少 2 个成功模型、匿名随机 A/B/C/D、三项 1~5 评分、全部评分后 Reveal，并将 `blind_scores.json` 写回同一 run。

## 5. 降级

- Gradio 未安装：纯 API 正常。
- unavailable 模型：明确状态/错误。
- 多模型 voice：各 Adapter 默认值。
- unsupported capability：UI 提前禁用，服务层最终校验。
- ResourceGuard 触发：直接报告，不无限重试。
