## Qwen3 native

Pinned `gabriele-mastrapasqua/qwen3-tts` revision `e56ec7e6eabbed608b13bfbd3fba431708b2077f`。支持 9 speakers、10 languages、seed；Arena 不宣称 semantic speed/streaming/voice-clone。

Hosted：INT8@2 RTF 1.787 / 3124MB；INT8@4 1.984 / 3129MB；INT4@4 2.432 / 2899MB。当前推荐 INT8@2；INT4 为低内存实验项。

均 disabled/experimental。

## Quant Blind AB harness

`prepare_qwen3_native_variants.py` 从同一 binary + model snapshot 一次生成 INT8/INT4 manifests，锁定相同 runtime revision/default voice/default language。

Arena 多模型 capability view 使用 common intersection：两套 quant backend 可共同选择同一 Vivian、zh 等；两者 seed=true，因此可固定同 seed。生成完成后使用既有 Blind AB 匿名评分 Naturalness / Intelligibility / Prosody，Reveal 后 `blind_scores.json` 与 benchmark report 一并归档。

状态：**评测工具链 ✅；人工评分结果 ⏳。** INT4 相同 seed/text 下曾出现不同生成时长，不能在人工验证前宣称与 INT8 质量等价。
