## 独立 Python / venv Worker

主 Arena 不要求把扩展模型依赖直接安装到 UI venv。`ModelSpec` 支持：

```yaml
worker_python: ""
worker_python_env: EDGETTS_ARENA_QWEN3_PYTHON
```

优先级：显式 `worker_python` > `worker_python_env` 对应环境变量 > 当前 Python 的普通 `spawn` worker。

默认环境变量：

```text
EDGETTS_ARENA_QWEN3_PYTHON
EDGETTS_ARENA_COSYVOICE_PYTHON
EDGETTS_ARENA_MELOTTS_PYTHON
```

external worker 使用版本化 JSON stdin/stdout 协议调用 `edgetts_arena.core.external_worker`，沿用 hard timeout、terminate/kill 与 PID/exit/signal/elapsed/oom_suspected 诊断。主进程只接收小型 JSON metadata，WAV 由 worker 写入主进程预先校验的 artifact 路径。

`doctor --workers` 会对配置中声明的专用解释器执行 Dummy WAV probe，用于检查 Python、项目 source、基础 worker 依赖与协议。它**不等价于模型 synthesis gate**。

## `/system/models` Worker 状态
