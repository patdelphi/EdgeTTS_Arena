## MeloTTS

- 官方仓库：`myshell-ai/MeloTTS`，MIT。
- 上游 API：`TTS(language=..., device='cpu')`，speaker 由 `hps.data.spk2id` 提供，`tts_to_file(..., output_path=None, speed=...)` 返回音频数组。
- 支持 EN/ES/FR/ZH/JP/KR；中文模型支持中英混读。
- 上游主仓库最近代码维护较慢，因此保持 experimental。
- 为禁止 benchmark 中隐式联网下载，本 Adapter 要求本地 `model.json`：

```json
{
  "language": "ZH",
  "config_path": "config.json",
  "ckpt_path": "G.pth"
}
```

- 状态：contract tests 完成；真实 CPU synthesis gate 待做。

## Gate 原则

在以下条件全部满足前，不把模型标记为正式可用：

1. 可复现本地模型包。
2. Python/runtime 依赖与项目支持范围可共存，或明确使用独立 venv worker。
3. CPU 输出 WAV 非空且 metadata/RTF 可记录。
4. 许可证和模型许可可追溯。
5. CI/目标设备真实 synthesis 通过。
