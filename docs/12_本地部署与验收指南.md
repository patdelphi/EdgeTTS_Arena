# 本地部署与验收指南

> 版本：v0.6（2026-09-03）  
> 目标：主 Arena 本地验收 + 扩展模型独立 runtime 验收。

## 1. 当前范围

**主 Arena 已达到本地部署测试条件。** Dummy、Piper、Kokoro、FastAPI、Gradio、Blind AB、Standard Suite、ZIP/report/environment 均有跨平台 CI 基线。

扩展模型默认 `experimental + disabled`。CosyVoice/MeloTTS/Qwen official FP32/Qwen native quant 均已有 hosted real CPU 证据；真实弱设备仍需单独验收。

## 2. 主 Arena

```bash
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[dev,ui,piper,kokoro]"

```

## 4. Qwen official FP32

按 pinned gate 准备独立 Python 3.11 + CPU PyTorch + `qwen-tts==0.1.1` + 本地 0.6B CustomVoice snapshot。

真实 smoke：

```bash
python scripts/real_model_smoke.py qwen3 \
  --model-path models/qwen3/Qwen3-TTS-12Hz-0.6B-CustomVoice \
  --voice Vivian --language zh \
  --text "你好，这是一条 EdgeTTS Arena 的 Qwen3 CPU 验证语音。" \
  --threads 2 --output exports/qwen3-local.wav --report exports/qwen3-local.json
```

hosted 功能 baseline：RTF 5.315 / peak RSS 5317.8MB。

## 5. Qwen native INT8

先编译 pinned pure-C runtime，并准备官方同一 CustomVoice snapshot，然后生成本地 manifest：

```bash
python scripts/prepare_qwen3_native_manifest.py \
  --binary runtime/qwen3-tts-c/qwen_tts \
  --model-dir models/qwen3/Qwen3-TTS-12Hz-0.6B-CustomVoice \
  --runtime-revision e56ec7e6eabbed608b13bfbd3fba431708b2077f \
  --quantization int8 --default-voice Vivian --default-language Chinese \
  --output models/qwen3-native/int8/model.json
```

配置建议：

```yaml
- id: qwen3-tts-0.6b-native-int8
  enabled: true
  adapter: qwen3_native
  model_path: ./models/qwen3-native/int8/model.json
  keep_in_memory: false
  num_threads: 2
  experimental: true
  language_control: true
```

当前 hosted INT8@2 baseline：RTF 1.787 / peak RSS 3124MB。该值比官方 FP32 路线更适合作为后续端侧候选，但仍不是树莓派/ARM 性能承诺。

**不要预设 `OPENBLAS_NUM_THREADS`**；pinned native runtime 自己根据 `--threads` 管理 OpenBLAS。

INT4 可通过 `--quantization int4` 生成另一 manifest。当前 hosted INT4@4 RTF 2.432 / peak RSS 2899MB，只作为低内存实验项；在完成 Blind AB 前不做音质等价声明。

## 6. Language control

API 请求：`config.language`；CLI：`edgetts-arena suite ... --language zh`；Gradio：单模型 Qwen/Kokoro 时显示 Language 下拉。

只在模型 `language_control=true` 时使用。MeloTTS 当前语言由 descriptor 固定，不要给它传全局 language override。

## 7. 启用原则

主 Arena ready 不依赖扩展模型。扩展模型启用前至少检查：本地资产、runtime pin、真实 synthesis、WAV sanity、RTF/RSS、许可证、目标设备资源。

Qwen native INT8 已达到 hosted 实验启用条件，但仍保持默认 disabled，直到具体目标设备验证完成。
