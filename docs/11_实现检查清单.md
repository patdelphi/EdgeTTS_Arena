# 实现检查清单

> 用于每个 Stage 完成后的快速自检。

## Stage 0

- [ ] `pip install -e .` 成功
- [ ] `pytest` 无模型环境通过
- [ ] Dummy Adapter 可生成音频
- [ ] config / logging / errors 有统一入口

## Stage 1

- [ ] Adapter capability 契约固定
- [ ] ModelRegistry 支持 load/status/unload
- [ ] MetricsCollector 不依赖具体 Adapter
- [ ] 非流式模型 TTFB 为 `None`
- [ ] timeout 可回收 worker
- [ ] ResourceGuard 可配置

## Stage 2

- [ ] Piper 实机 CPU 生成成功
- [ ] Kokoro 实机 CPU 生成成功
- [ ] 每个 Adapter 有 contract tests
- [ ] Qwen3 未完成时保持 experimental/unavailable，不伪造支持

## Stage 3

- [ ] `GET /api/v1/system/models`
- [ ] `POST /api/v1/benchmark/run`
- [ ] 单模型失败不影响其他模型
- [ ] download/export 无路径穿越
- [ ] streaming capability gate 生效

## Stage 4

- [ ] UI 参数由 capability 驱动
- [ ] Sequential 默认
- [ ] `ttfb=null` 显示 N/A
- [ ] Blind 匿名映射可追溯到 run_id

## Stage 5

- [ ] TC-01~05 可执行
- [ ] environment snapshot 完整
- [ ] report 含 model/runtime/quantization/version
- [ ] ZIP 可复现本轮输入和输出

## Stage 6

- [ ] Windows/Linux/macOS smoke test
- [ ] concurrent 与 sequential 报告分开
- [ ] memory/timeout 故障可恢复
- [ ] 第二批模型不破坏 MVP baseline

## 文档同步规则

每次改变以下内容时必须同步文档：

- API path/schema
- Adapter capability
- Model status enum
- Benchmark metric definition
- 配置字段
- Stage 状态
