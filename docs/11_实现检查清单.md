## 边界

- bootstrap ready ≠ real synthesis verified；
- Blind AB harness ready ≠ quality verified；
- target-device acceptance ready ≠ hardware verified；
- Concurrent calibration tooling ready ≠ real-device concurrency verified；
- `cgroup_oom_kill_observed` 是 cgroup-wide observed evidence，不等于证明具体 PID OOM；
- hosted ARM64/1-CPU smoke 不等于树莓派/真实弱设备性能结论。
