# 接口协议与数据规范

> 版本：API v1.0 Draft 5 ｜ Stage 6 hardening in progress ｜ 本地同步接口

## 通用约定

Base path：`/api/v1`。时间戳使用 UTC ISO 8601；指标使用 ms / MB / percent。`GET /healthz` 为健康检查。

## 系统与模型

### `GET /api/v1/system/models`

返回 system environment、模型状态、experimental、capabilities 和 voices。环境快照包含 OS/release/arch、CPU、RAM、Python、package versions 和 thread settings。

## 单轮同步 Benchmark

### `POST /api/v1/benchmark/run`

1~4 模型，同步最终返回；`run_id` 是归档 ID。单模型失败不使整轮失败。

Stage 6 增加资源计划字段：

- `execution_profile`: Sequential=`baseline`，Concurrent=`pressure`。
- `requested_cpu_threads_per_model`: 用户请求值。
- `cpu_threads_per_model`: ResourceGuard 计算后的有效值。
- `total_threads_budget`: 本轮总线程预算。
- `resource_warnings`: 自动 clamp 等提示。

Concurrent 在创建线程池前检查：

1. soft/hard memory guard。
2. `max_concurrent_models`。
3. `model_count × min_available_memory_mb_per_concurrent_model`。
4. `logical_cores // model_count` 的公平线程份额。

预算不足返回 `2001`，不等待 OOM。

## 标准 Benchmark

### `GET /api/v1/benchmark/presets`

返回 TC-01~TC-05、默认 warm-up=1 / measured=3。

### `POST /api/v1/benchmark/suite`

固定 Sequential，保留 raw measurements，并聚合 count/mean/median/min/max/P95/variance。同一 case/model 一次 load 后 warm-up 再 measured repeats。

## Artifacts

`GET /api/v1/audio/download/{run_id}/{filename}` 仅允许安全 WAV basename。`GET /api/v1/export/{run_id}` 返回 WAV + benchmark report + environment + optional blind scores。

## Streaming

`WS /api/v1/tts/stream?model=<model_id>` 仅对 streaming capability 开放；真实首块才统计 TTFB。

## 错误码

| 应用码 | HTTP | 含义 |
|---:|---:|---|
| 1001 | 400 | 输入/路径无效 |
| 1002 | 404 | 模型、run、case 或音频不存在/不可用 |
| 1003 | 409 | 参数与 capability 冲突 |
| 2001 | 503 | CPU/并发/资源预算不足 |
| 2002 | 503 | hard memory guard |
| 3001 | 504 | 推理超时 |
| 3002 | 500 | 模型/worker 内部错误 |
