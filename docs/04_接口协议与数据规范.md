# 接口协议与数据规范

> 版本：API v1.0 Draft 2 ｜ MVP 同步接口基线

## 1. 通用约定

Base path：`/api/v1`

成功 envelope：

```json
{"code": 200, "message": "success", "data": {}}
```

失败 envelope：

```json
{
  "code": 1001,
  "message": "invalid request",
  "data": null,
  "error": {"type": "validation_error", "details": []}
}
```

- HTTP 状态码表达传输/系统级结果。
- `code` 表达应用错误码。
- 时间戳使用 UTC ISO 8601。
- 所有音频指标统一使用 ms / MB / percent。

## 3. 同步 Arena Benchmark

### `POST /api/v1/benchmark/run`

MVP 中该接口**同步执行并返回最终结果**。`run_id` 是归档 ID，不代表后台 job。

Request：

```json
{
  "text": "随着大模型向端侧迁移……",
  "models": ["piper", "kokoro-82m"],
  "execution_mode": "sequential",
  "cpu_threads_per_model": 4,
  "config": {
    "voice": null,
    "speed": 1.0,
    "seed": 42,
    "sample_rate": null
  }
}
```

字段约束：

- `models`：1~4 个。
- `execution_mode`：`sequential | concurrent`。
- `cpu_threads_per_model`：默认 4，最大值由 ResourceGuard 决定。
- 不支持的可选参数必须依据 capability 返回 warning 或 validation error。

Response：

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "run_id": "run_20260903_101822_ab12cd",
    "started_at": "2026-09-03T10:18:22Z",
    "completed_at": "2026-09-03T10:18:28Z",
    "execution_mode": "sequential",
    "results": [
      {
        "model_id": "kokoro-82m",
        "status": "success",
        "audio_url": "/api/v1/audio/download/run_.../kokoro-82m.wav",
        "metrics": {
          "inference_time_ms": 420.5,
          "audio_duration_ms": 3800.0,
          "rtf": 0.111,
          "ttfb_ms": null,
          "peak_rss_mb": 342.1,
          "rss_delta_mb": 64.5,
          "avg_cpu_usage_pct": 36.2
        },
        "warnings": [],
        "error": null
      }
    ]
  }
}
```

单模型失败示例：

```json
{
  "model_id": "qwen3-tts-0.6b",
  "status": "error",
  "audio_url": null,
  "metrics": null,
  "warnings": [],
  "error": {"code": 3001, "type": "inference_timeout", "message": "model inference timed out"}
}
```

## 4. Audio Download

### `GET /api/v1/audio/download/{run_id}/{filename}`

- 仅允许访问当前 export 根目录内的安全文件名。
- 禁止 `..`、绝对路径和任意本地文件读取。
- Content-Type：`audio/wav`。

## 5. Streaming

### `WS /api/v1/tts/stream?model=<model_id>`

仅当 `capabilities.streaming=true` 时开放。

客户端 start event：

```json
{"action":"start","text":"你好，这里是流式测试。","voice":null,"speed":1.0}
```

服务端：

1. JSON `started` event。
2. 二进制 PCM/WAV chunk。
3. 首块可播放音频时发送 `first_chunk`。
4. 完成后发送 `complete`。

```json
{"event":"first_chunk","ttfb_ms":320.0,"chunk_idx":0}
```

```json
{"event":"complete","audio_duration_ms":2100.0,"rtf":0.58}
```

## 6. Export

### `GET /api/v1/export/{run_id}`

返回 ZIP：

- `audio/*.wav`
- `benchmark_report.json`
- `environment.json`

## 7. 错误码

| 应用码 | HTTP | 含义 |
|---:|---:|---|
| 1001 | 400 | 输入无效 |
| 1002 | 404 | 模型不存在/不可用 |
| 1003 | 409 | 参数与模型 capability 冲突 |
| 2001 | 503 | CPU/系统资源暂不可用 |
| 2002 | 503 | 内存保护触发 |
| 3001 | 504 | 推理超时 |
| 3002 | 500 | 模型推理内部错误 |
