# 接口协议与数据规范

> 版本：API v1.0 Draft 7 ｜ Stage 6 实现基线 ｜ 本地同步接口

## 1. 通用约定

Base path：`/api/v1`。时间戳使用 UTC ISO 8601；指标使用 ms / MB / percent；文本默认最大 1000 字符。

## 2. 系统与模型

### `GET /api/v1/system/models`

返回 system environment、模型状态、experimental、capabilities、voices 与 worker 路由状态。

模型 capability 可包含：

```json
{
  "streaming": false,
  "seed": true,
  "speed": false,
  "voices": true,
  "voice_clone": false,
  "language_control": true,
  "languages": ["zh","en","ja"]
}
```

`languages` 表示模型支持/声明的语言集合；只有 `language_control=true` 才表示 benchmark 可显式下发 `config.language`。例如 MeloTTS descriptor 可声明支持语言，但当前模型实例由本地 descriptor 固定语言，因此不自动视为可切换语言。

Worker 字段：`worker_mode=in_process|spawn|external`、`worker_python_configured`。API 不返回专用 Python 的绝对路径。

## 3. 单轮同步 Benchmark

### `POST /api/v1/benchmark/run`

Request 示例：

```json
{
  "text":"你好",
  "models":["qwen3-tts-0.6b-native-int8"],
  "execution_mode":"sequential",
  "cpu_threads_per_model":2,
  "config":{
    "voice":"Vivian",
    "language":"zh",
    "speed":1.0,
    "seed":42,
    "sample_rate":null
  }
}
```

规则：

- models 1~4。
- `language` 可省略；输入会 trim + lowercase。
- 指定 language 但模型 `language_control=false` → per-model `1003 capability_conflict`。
- 指定不在 `capabilities.languages` 中的 language → `1003`。
- speed/voice capability 冲突 → `1003`。
- seed 不支持时记录 warning。
- sample-rate override 当前只记录 warning。
- 非流式 `ttfb_ms=null`。
- Sequential=`baseline`；Concurrent=`pressure`。

## 4. Isolated worker diagnostics

`keep_in_memory=false` 的 spawn/external worker 返回：mode、pid、exit_code、elapsed_ms、termination、signal、oom_suspected、runtime/protocol。external JSON 协议当前版本 1；错误/traceback 有界 tail 上限 8192 字符。

- timeout → `3001`
- worker crash/protocol failure → `3002`
- 显式 MemoryError → `2002`
- SIGKILL 仅标记 `oom_suspected=true`

native Qwen Adapter 本身在 Python worker 中启动本地 C 子进程；MetricsCollector 会合并 Adapter metadata 中的子进程 peak RSS/CPU，避免只统计 Python wrapper。

## 5. Repeated Benchmark Suite

### `POST /api/v1/benchmark/suite`

```json
{
  "models":["qwen3-tts-0.6b-native-int8"],
  "case_ids":["TC-01","TC-02"],
  "cpu_threads_per_model":2,
  "warmup_runs":1,
  "measured_runs":3,
  "config":{"voice":null,"language":"zh","speed":1.0,"seed":42,"sample_rate":null}
}
```

固定 Sequential。每个 case/model 一次 load 后完成 warm-up + repeats；输出 raw measurements 与 count/mean/median/min/max/p95/variance aggregate。

CLI 等价入口：

```bash
edgetts-arena suite --models qwen3-tts-0.6b-native-int8 --cases TC-01 --threads 2 --language zh
```

## 6. Run Artifact

单轮：`audio/<model>.wav` + `benchmark_report.json` + `environment.json`。Suite：`audio/<case>__<model>.wav` + 同类 JSON。Blind Reveal 后可增加 `blind_scores.json`。

## 7. Streaming

`WS /api/v1/tts/stream?model=<model_id>` 仅对 `streaming=true` 开放。external/native 同步 Benchmark 接入不意味着跨进程 streaming 已实现。

## 8. 错误码

| 应用码 | HTTP | 含义 |
|---:|---:|---|
| 1001 | 400 | 输入/路径无效 |
| 1002 | 404 | 模型、run、case 或音频不存在/不可用 |
| 1003 | 409 | 参数与 capability 冲突 |
| 2001 | 503 | CPU/系统资源暂不可用 |
| 2002 | 503 | 内存保护触发 |
| 3001 | 504 | 推理超时 |
| 3002 | 500 | 模型推理/worker 内部错误 |

## 9. 非 API 配置

`ModelSpec` 支持：`worker_python`、`worker_python_env`、`language_control`。native Qwen 通过本地 `model.json` manifest 固定 binary/model_dir/runtime_revision/quantization/default voice/default language。
