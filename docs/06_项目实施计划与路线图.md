## Qwen3 hosted baseline

- official FP32@2：RTF 5.315 / 5318MB。
- native INT8@2：RTF 1.787 / 3124MB。
- native INT8@4：RTF 1.984 / 3129MB。
- native INT4@4：RTF 2.432 / 2899MB。

当前推荐候选：INT8@2；INT4 仍需人工质量验证。

## Concurrent calibration

`target_device_concurrent_calibration.py` 每轮执行 Sequential baseline → Concurrent pressure，按模型计算 RTF slowdown、RSS delta 与 CPU 变化，同时保存 effective thread budget 与 ResourceGuard warnings。阈值由目标设备 SLA 显式给出，不使用 hosted runner 数字作为真机承诺。

## OOM evidence

- explicit MemoryError → `worker_memory_error`；
- SIGKILL + Linux cgroup v2 `oom_kill` 增量 → `cgroup_oom_kill_observed`；
- 裸 SIGKILL → `sigkill_suspected`；
- timeout watchdog terminate/kill → `none`。

## Bootstrap

- Python extended profiles：`bootstrap_extended_model.py`；
- native Qwen：`bootstrap_qwen3_native.py`；
- 默认均为 plan-only；重下载/构建必须显式 `--execute`；
- bootstrap/preflight、real synthesis、human quality、target-device performance 分开标记。

## Stage 6 当前优先顺序

1. ✅ 工程侧：runtime/adapters/metrics/worker/bootstrap/OOM/target acceptance/concurrent calibration tools。
2. 🟡 实际执行 INT8/INT4 多文本/多语言人工 Blind AB。
3. 🟡 在真实 ARM/弱设备运行 acceptance。
4. 🟡 在真实目标设备运行 Concurrent calibration，并据此收敛资源预算。

剩余事项主要需要外部真实设备或人工听评数据；不得用 hosted CI 结果替代。
