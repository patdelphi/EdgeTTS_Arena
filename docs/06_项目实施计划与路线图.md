## Stage 6 Watchdog 当前口径

- `BenchmarkService` / `RepeatedBenchmarkService` 默认启用进程隔离；仅嵌入式调用或测试可显式 `isolate_model_processes=False`。
- `keep_in_memory=false`：单轮与 Suite 使用 `spawn` worker，支持 terminate/kill hard timeout。
- Standard Suite 一个 `case/model` 作为一个 worker group，在 worker 内完成 warm-up + repeats。
- timeout → `3001`；worker crash → `3002`；故障后 Registry 状态恢复为 `unloaded`。
- isolated result 记录 PID / exit code / signal / elapsed / termination；显式 MemoryError → `2002`。
- SIGKILL 只记 `oom_suspected=true`（可能 OOM 或外部 kill），跨平台不伪造内核级确定归因。
- `keep_in_memory=true`：暂保留进程内常驻，明确 warning，不宣称 hard timeout。
- 下一步：第二批 Adapter 与弱算力设备验证；如目标平台提供 cgroup/kernel OOM event，再增加平台特定确定归因。
