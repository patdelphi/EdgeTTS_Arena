2. Windows、macOS、Linux 均通过 `edgetts-arena doctor`、Dummy WAV、FastAPI health/preset 与 spawn worker smoke。
3. UI job 通过 `edgetts-arena doctor --ui` 与 Gradio mounted smoke。
4. Piper/Kokoro 真实 CPU synthesis gate 通过。

6. Qwen3 官方 CPU FP32 功能 gate 已通过，但不作为主 Arena ready 前置条件，且因端侧性能未达标继续 experimental/disabled。

## Qwen3 FP32 baseline

首次 hosted real CPU gate：GitHub-hosted Ubuntu x86_64 / Python 3.11 / `qwen-tts==0.1.1` / CPU PyTorch / 2 threads / Vivian / Auto language。

- audio duration: 9.04s
- inference: 48.05s
- RTF: 5.315
- peak RSS: 5317.8MB
- inference RSS delta: 862.3MB
- average process CPU: ~200%
- WAV sanity: finite、非静音、24kHz ✅

结论：官方 FP32 CPU runtime 是有效功能基线，但不是 EdgeTTS-Arena 的目标端侧性能路线。

## Stage 6 Watchdog 与 Worker 当前口径

- `BenchmarkService` / `RepeatedBenchmarkService` 默认启用进程隔离。
- `keep_in_memory=false` 且未配置外部 Python：使用当前解释器的 `spawn` worker。
- `keep_in_memory=false` 且配置 `worker_python`/`worker_python_env`：使用版本化 JSON stdin/stdout external worker。
- 默认扩展模型环境变量：`EDGETTS_ARENA_QWEN3_PYTHON`、`EDGETTS_ARENA_COSYVOICE_PYTHON`、`EDGETTS_ARENA_MELOTTS_PYTHON`。
- `edgetts-arena doctor --workers` / `--worker MODEL_ID` 做协议 + Dummy WAV probe；不代替真实模型 synthesis gate。
- `/api/v1/system/models` 暴露 `worker_mode=in_process|spawn|external` 与 `worker_python_configured`，不回传本机 Python 绝对路径。
- Standard Suite 一个 `case/model` 作为一个 worker group，在 worker 内完成 warm-up + repeats。
- timeout → `3001`；worker crash → `3002`；显式 MemoryError → `2002`；SIGKILL 仅记 `oom_suspected=true`。
- GitHub-hosted原生 ARM64 与 1-CPU runner 已通过；ResourceGuard 使用 affinity/cgroup/host 中最保守资源预算。
- MeloTTS、CosyVoice 300M SFT、Qwen3 0.6B CustomVoice hosted real CPU synthesis 均已通过功能 gate。
- 下一步是 Qwen3 量化/低内存路线和真实弱算力目标设备验证。
