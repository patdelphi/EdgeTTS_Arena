## Qwen3 hosted baselines

- official FP32@2：RTF 5.315 / 5318MB。
- native INT8@2：RTF 1.787 / 3124MB。
- native INT8@4：RTF 1.984 / 3129MB。
- native INT4@4：RTF 2.432 / 2899MB。

当前选择：INT8@2；INT4 仅作为低内存实验项。相同 seed/text 下 INT4 与 INT8 时长不同，音质必须单独验证。

## Quant quality workflow

1. `prepare_qwen3_native_variants.py` 生成匹配 INT8/INT4 manifests。
2. 默认 catalog 提供两个 disabled/experimental model ids。
3. Arena 多模型计算共同 voice/language 交集。
4. 固定同一 voice/language/seed 后生成两条音频。
5. Blind AB 匿名评分 Naturalness / Intelligibility / Prosody。
6. Reveal 后 `blind_scores.json` + benchmark report 一并归档。
