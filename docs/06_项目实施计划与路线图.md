## Qwen3 hosted baselines

官方 FP32：2 threads，RTF 5.315，peak RSS 5317.8MB。

native 同文本/seed 对照：

| Route | Threads | RTF | Peak RSS |
|---|---:|---:|---:|
| INT8 | 2 | **1.787** | 3124MB |
| INT8 | 4 | 1.984 | 3129MB |
| INT4 | 4 | 2.432 | **2899MB** |

工程决策：

1. 官方 FP32 保留为官方兼容/功能基线。
2. native INT8@2 作为当前 CPU 优化候选；默认配置线程数调整为 2。
3. INT4 只作为更低内存实验选项，不作为默认推荐；相同 seed/text 下其音频时长与 INT8 不同，必须完成质量 A/B 后才能讨论质量等价。
4. hosted 结果不等于树莓派/ARM/低功耗设备结果。

## Stage Gate

配置 gate 不等于 gate 已通过。只有 CI/目标机真实 synthesis 成功后才标记 verified；性能与质量是两个独立 gate。hosted RTF/RSS 只能作为工程基线，不作为设备性能承诺。
