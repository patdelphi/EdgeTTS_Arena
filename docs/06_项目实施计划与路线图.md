## Stage 6 Watchdog 当前口径

- `BenchmarkService` / `RepeatedBenchmarkService` 默认启用进程隔离；仅嵌入式调用或测试可显式 `isolate_model_processes=False`。
- `keep_in_memory=false`：单轮与 Suite 使用 `spawn` worker，支持 terminate/kill hard timeout。
- Standard Suite 一个 `case/model` 作为一个 worker group，在 worker 内完成 warm-up + repeats。
- timeout → `3001`；worker crash → `3002`；故障后 Registry 状态恢复为 `unloaded`。
- isolated result 记录 PID / exit code / signal / elapsed / termination；显式 MemoryError → `2002`。
- SIGKILL 只记 `oom_suspected=true`（可能 OOM 或外部 kill），跨平台不伪造内核级确定归因。
- `keep_in_memory=true`：暂保留进程内常驻，明确 warning，不宣称 hard timeout。
- GitHub-hosted 原生 ARM64 与 1-CPU runner 已通过；ResourceGuard 使用 process/affinity/cgroup/host 中最保守 CPU 预算，并使用 host available/cgroup remaining 中更小的内存预算。
- MeloTTS real CPU gate：GitHub-hosted Ubuntu 24.04 / Python 3.10 / 2 threads，pinned source + pinned Chinese model，真实 synthesis、WAV/JSON artifact 与 audio sanity gate 全通过。历史单次记录为 4.415s 音频、inference 8.005s、RTF 1.813、peak RSS 2960.8 MB；只用于 gate 追溯，不作为性能承诺。
- CosyVoice 300M SFT real CPU gate：GitHub-hosted Ubuntu 24.04 / Python 3.10 / CPU-only PyTorch + ONNX Runtime / 2 threads；真实 synthesis 与 audio sanity 全通过。单次记录为 4.098s 音频、inference 17.875s、RTF 4.362、peak RSS 4181 MB；只用于 gate 追溯，不作为性能承诺。
- CosyVoice offline preflight：WeText 5 个 FST 先显式下载并生成 SHA-256 manifest；随后将 `snapshot_download()` 替换为调用即失败，Adapter 仍可从本地 FST load model。
- 下一步：真实弱算力设备验证；如目标平台提供 cgroup/kernel OOM event，再增加平台特定确定归因。
