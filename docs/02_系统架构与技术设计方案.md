## 2. 统一 Adapter 契约

Adapter 只负责模型生命周期和推理，不直接承担统一性能统计。

```python
from abc import ABC, abstractmethod
from dataclasses import dataclass, field
from typing import Any, Iterator
import numpy as np

@dataclass(frozen=True)
class TTSCapabilities:
    streaming: bool = False
    seed: bool = False
    speed: bool = True
    voices: bool = True
    voice_clone: bool = False
    languages: tuple[str, ...] = ()

@dataclass
class TTSOutput:
    audio: np.ndarray
    sample_rate: int
    metadata: dict[str, Any] = field(default_factory=dict)

class BaseTTSAdapter(ABC):
    id: str
    capabilities: TTSCapabilities

    @abstractmethod
    def load_model(self, model_path: str, *, device: str = "cpu", num_threads: int = 4) -> None: ...

    @abstractmethod
    def infer(self, text: str, *, voice: str | None = None, speed: float = 1.0, **kwargs: Any) -> TTSOutput: ...

    def infer_stream(self, text: str, **kwargs: Any) -> Iterator[TTSOutput]:
        raise NotImplementedError("streaming is not supported by this adapter")

    @abstractmethod
    def unload_model(self) -> None: ...
```

### 2.1 约束

- `infer_stream()` 不是所有模型的必选能力。
- `capabilities.streaming == false` 时，API/UI 不得开放流式调用。
- Adapter 返回模型原始 metadata；统一 RTF/RSS/CPU/TTFB 由 `MetricsCollector` 计算。
- 所有输出转换为 mono `float32`，推荐范围 `[-1.0, 1.0]`；采样率保留模型实际值。

## 3. Core Runtime

### 3.1 ModelRegistry

职责：

- 加载 `models_config.yaml`。
- 注册 Adapter factory。
- 查询状态/capability。
- lazy load / unload。
- 记录最近使用时间，供 LRU 卸载策略使用。

### 3.2 MetricsCollector

统一采集：

- wall-clock inference time。
- audio duration。
- RTF。
- worker RSS baseline / peak / delta。
- worker CPU usage。
- streaming 首个**可播放音频 chunk**时间。

非流式模型 `ttfb_ms = null`。

### 3.3 ProcessRunner

MVP 支持两种执行策略：

1. `sequential`：逐模型执行，默认 Benchmark 模式。
2. `concurrent`：并行 worker，面向吞吐/资源竞争测试。

实现优先级：

- Stage 0/1 可先使用同一 Python 环境中的 subprocess/process worker。
- `ProcessPoolExecutor` 只解决进程级隔离，不解决 Python 包版本冲突。
- 确有依赖冲突时，Phase 2 引入独立 venv worker，通过 JSON IPC/stdin-stdout 或本地 socket 通讯。

### 3.4 ResourceGuard

- 推理前检查可用内存。
- 限制线程数。
- timeout 后终止 worker。
- CPU affinity：Linux/Windows 可用时启用；macOS 或不支持环境降级，不影响运行。

## 4. API 层设计原则

- REST API 使用统一 envelope：`code/message/data`。
- Benchmark MVP 是**同步接口**；`run_id` 仅用于归档，不表示后台任务。
- 单模型失败使用结果级 `status=error`，只在整个请求无法执行时返回 4xx/5xx。
- Phase 2 如需异步长压测，另增 `/api/v1/jobs/...`，不改变同步接口语义。

## 6. 配置边界

不得把以下信息散落硬编码在 Adapter 中：

- 模型本地路径 / 下载标识。
- 线程数。
- timeout。
- 内存阈值。
- 默认 voice / language。
- 量化 variant。

统一由配置层提供，Adapter 只定义合理默认值和能力限制。
