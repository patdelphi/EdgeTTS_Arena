# 开发测试用例与环境配置

> 版本：v0.2 ｜ Stage 0 可直接按本文初始化

## 1. 推荐依赖管理

优先使用 `pyproject.toml`，把模型专用依赖放入 optional extras，避免基础环境一次安装所有重依赖。

示例结构：

```toml
[project]
name = "edgetts-arena"
version = "0.1.0"
requires-python = ">=3.10,<3.13"
dependencies = [
  "fastapi>=0.110",
  "uvicorn[standard]>=0.28",
  "pydantic>=2.6",
  "numpy>=1.24",
  "soundfile>=0.12",
  "psutil>=5.9",
]

[project.optional-dependencies]
ui = ["gradio>=4.20"]
onnx = ["onnxruntime>=1.17"]
dev = ["pytest>=8", "pytest-cov>=5", "httpx>=0.27"]
```

Torch CPU 不与 requirement 行混写 index URL；按平台单独安装。

## 2. Dummy Adapter 测试

```python
import numpy as np
from edgetts_arena.core.base_adapter import BaseTTSAdapter
from edgetts_arena.core.capabilities import TTSCapabilities

class DummyTTSAdapter(BaseTTSAdapter):
    id = "dummy"
    capabilities = TTSCapabilities(streaming=True, seed=True, speed=True, voices=True)

    def load_model(self, model_path: str, *, device: str = "cpu", num_threads: int = 4) -> None:
        self.is_loaded = True
        self.sample_rate = 24000

    def infer(self, text: str, *, voice: str | None = None, speed: float = 1.0, **kwargs):
        duration = 1.0
        t = np.linspace(0, duration, int(self.sample_rate * duration), False)
        audio = (0.1 * np.sin(2 * np.pi * 440 * t)).astype(np.float32)
        return audio, self.sample_rate

    def infer_stream(self, text: str, **kwargs):
        yield np.zeros(2400, dtype=np.float32), self.sample_rate

    def unload_model(self) -> None:
        self.is_loaded = False
```

正式代码的返回类型以 `02_系统架构与技术设计方案.md` 中 `TTSOutput` 为准；上例仅展示 Stage 0 行为。

## 3. 单元测试矩阵

### Core

- Adapter lifecycle。
- capability validation。
- ModelRegistry 状态转换。
- MetricsCollector RTF 计算。
- 非流式 TTFB = `None`。
- timeout worker 回收。
- ResourceGuard soft/hard threshold。

### API

- `/system/models` schema。
- `/benchmark/run` 单模型成功。
- 多模型部分失败。
- unsupported capability。
- 输入过长。
- audio download path traversal。

### Export

- 生成 WAV。
- 生成 `benchmark_report.json`。
- 生成 `environment.json`。
- ZIP 内容完整。

## 4. Smoke Test

无真实模型环境必须能完成：

```text
Dummy load
  -> POST benchmark/run
  -> metrics
  -> WAV
  -> report JSON
  -> export ZIP
```

这条链路是 CI 的最低保障。

## 5. 真实模型测试标记

```python
@pytest.mark.model
@pytest.mark.slow
```

默认 CI 不下载大模型。真实模型测试通过环境变量启用，例如：

```bash
EDGETTS_ARENA_RUN_MODEL_TESTS=1 pytest -m model
```

## 6. 配置文件建议

`config/models_config.yaml`：模型路径、启用状态、线程数、timeout、keep-in-memory、experimental。

`config/benchmark_presets.json`：TC-01~TC-05。

所有默认值可被环境变量或 CLI 覆盖，但最终生效配置必须写入 benchmark report。
